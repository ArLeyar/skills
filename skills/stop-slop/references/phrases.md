# Phrases to Remove

## Throat-Clearing Openers

Remove these. State the content directly.

- "Here's the thing:"
- "Here's what [X]" / "Here's this [X]" / "Here's that [X]" / "Here's why [X]"
- "The uncomfortable truth is"
- "It turns out"
- "The real [X] is"
- "Let me be clear"
- "The truth is,"
- "I'll say it again:"
- "I'm going to be honest"
- "Can we talk about"
- "Here's what I find interesting"
- "Here's the problem though"

Any "here's what/this/that" construction is throat-clearing. Cut it, state the point.

## Emphasis Crutches

Add no meaning. Delete.

- "Full stop." / "Period."
- "Let that sink in."
- "This matters because"
- "Make no mistake"
- "Here's why that matters"

## Resume / CV Killers (2026 AI-Fingerprint List)

Recruiters in 2026 flag these as instant AI-generated signals. 49% of hiring managers auto-reject resumes containing them. Strip from any CV, cover letter, LinkedIn bullet, or professional summary.

**Banned action verbs (top fingerprints):**

| Avoid | Use instead (truthful only) |
|-------|------------------------------|
| Spearheaded | Led, Started |
| Orchestrated | Coordinated, Ran |
| Championed | Pushed for, Advocated for |
| Revolutionized | Rebuilt, Changed |
| Pioneered | Was first to, Introduced |
| Empowered | Enabled, Helped |
| Catalyzed | Triggered, Started |
| Drove | Led (if true), Pushed for |
| Streamlined | Simplified, Cut steps in |
| Optimized (vague) | Reduced X by Y% (specific) |

**Banned adjectives / openers:**

- "Results-driven professional with a proven track record" — single most flagged opener
- "Passionate about..."
- "Dynamic / transformative / cutting-edge"
- "Strategic visionary / thought leader"
- "Self-starter / detail-oriented / team player"
- "Unwavering commitment to..."
- "At the intersection of X and Y"
- "Multifaceted / vibrant"

**Verb-discipline rule (CV-specific):**

Never upgrade involvement level during rewrite:
- Source says "Contributed to" → output cannot become "Led" or "Built"
- Source says "Evaluated" / "Prototyped" → cannot become "Shipped" or "Deployed"
- Source says "Supported" → cannot become "Owned"

**Structural CV anti-patterns:**

- All bullets same length (3 lines each) → AI signature
- Every bullet starts with a power verb → humans vary (`Built X` / `When Y broke, fixed Z` / `Result: Q`)
- Perfect JD-resume alignment with no original content → flag for "hallucinated coverage"
- Smoothed-over employment gaps with no actual gap → recruiter cross-checks LinkedIn
| Paradigm shift | Change |
| Cutting-edge | New, modern |
| Groundbreaking | New, first |
| Ever-evolving | Changing |
| Pivotal | Important |
| Transformative | (be specific about what changed) |

## Adverbs

Kill all adverbs. No -ly words. No softeners, no intensifiers, no hedges.

- "really", "just", "literally", "genuinely", "honestly"
- "simply", "actually", "deeply", "truly", "fundamentally"
- "inherently", "inevitably", "interestingly"
- "importantly", "crucially", "significantly"

## Filler Phrases

- "At its core"
- "In today's [X]"
- "It's worth noting"
- "At the end of the day"
- "When it comes to"
- "In a world where"
- "The reality is"

## Meta-Commentary

Remove self-referential asides.

- "Hint:" / "Plot twist:" / "Spoiler:"
- "You already know this, but"
- "But that's another post"
- "X is a feature, not a bug"
- "Dressed up as"
- "The rest of this essay explains..."
- "Let me walk you through..."
- "In this section, we'll..."
- "As we'll see..."
- "I want to explore..."

## Performative Emphasis

- "creeps in"
- "I promise"
- "They exist, I promise"

## Telling Instead of Showing

- "This is genuinely hard"
- "This is what leadership actually looks like"
- "actually matters"

## Vague Declaratives

Kill sentences that announce importance without naming the thing.

- "The reasons are structural"
- "The implications are significant"
- "This is the deepest problem"
- "The stakes are high"
- "The consequences are real"

Replace with the specific thing.
